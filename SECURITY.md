# Security policy

## Supported release

Security reports currently cover v0.1.2 on the exact POCO F7/onyx Infinity-X4.1 Android17 setup documented in README. Other devices/ROMs and legacy Konoha outputs are not supported.

## Report privately

Use GitHub **Security → Report a vulnerability** on this repository. Do not put exploitable vulnerability details, tokens, raw phone crash buffers, boot images or personal identifiers in public issues. Include affected version, minimal reproduction, impact and redacted diagnostics. There is no guaranteed response time or paid bounty.

Normal installation/compatibility questions belong in Issues or the linked discussion group. Only test wireless features on your own or explicitly authorized networks.

## Project safeguards

Official release assets live on this repository's Releases page. Source and original licences remain public. Public code cannot technically prevent misuse; no policy here overrides upstream GPL or other component licence rights. Main-branch changes use pull requests; release tags are protected; Actions credentials are read-only by default. Do not disable installer guards, force mismatched driver CRCs, or remove CFI/KASAN to mask a defect.
